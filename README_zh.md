使用说明

使用方法:

1.  加载名单文件.
    界面上点击显示窗口,或者按"快捷键B",可以显示一行设置.
    点击"更多"按钮,弹出一个设置窗口.
    在说设置窗口的"抽签"一栏中点击"打开",可以选择名单文件.名单文件是一个文本文件,每行一个名字,空行会被忽略,名字前后的空白会被忽略.
2. 选中主界面,点击"开始"按钮,或者使用"快捷键P"进行抽签.
   在无滚动效果的模式下,点击一次"开始"按钮,随机显示一个名字.
   在有滚动效果的模式下,点击一下"开始"按钮,显示栏以一定的频率滚动显示名字,再点击一下"开始"按钮(此时显示"结束"字样),固定到某个名字上.
   滚动效果的打开或者关闭,可以在设置窗口中"界面"一栏的"无滚动效果"处勾选,或者使用"快捷键M"打开或者关闭.

    显示窗口的字体大小根据主窗体的大小会自动调节.
    点击显示窗口,会隐藏或者展示上面的一行常用设置,使用"快捷键B"可以达到同样效果.常用设置中的"无重复"勾选框控制新抽中的结果是否会合已抽中的结果重复.点击"历史记录"会弹出窗口显示已经抽中的名字的列表,从最新往最旧排序,重复抽中的名字只在第一次抽中的位置显示.单击"清空历史"会清空历史记录(此时会重新开始记录抽签历史,"无重复"功能只会控制不和清空后的历史重复).点击"更多"按钮弹出设置框.

详细设置:

  点击常用设置中的"更多"按钮打开配置窗口.常用设置可以通过点击显示名字的框,或"快捷键B"展示或隐藏.

  "配置"

  设置中的"配置"一栏,用于控制配置文件.路径显示了当前配置文件的路径,"加载"按钮用于重新读取当前配置文件,"打开"用于保存新的配置文件."保存"用于保存当前界面的设置到配置文件中."另存为"可以将配置文件保存到其他路径.
  程序退出时,会自动保存设置界面设置的内容到配置文件.配置文件可以保存在任意路径,从任意路径读取,但是无论配置文件从任何路径读取,程序目录下的"config.json"是主配置文件(其他配置文件中的设置优先级更高),程序打开时会自动创建这个文件,通常无需人为干预.
  如果要把同样配置的程序拷贝到另一台主机,建议保持配置文件的路径为"config.json",保存配置后,将程序和同目录下的"config.json"一同拷贝到新的主机.

  "抽签"

  "抽签"一栏中,展示了当前使用的名单列表的路径.点击"加载"会重新读取名单列表,"打开"可以打开新的名单列表,"另存为"可以把当前使用的名单列表保存到新的路径.
  "无重复"勾选框控制新抽取的名字是否会与历史重复.
  名单列表文件应为文本文件,每行一个名字,空行会被忽略,名字前后的空白会被忽略.文件应以UTF-8编码.

  "历史记录"

  "历史记录"一栏用于控制当前抽签的历史记录.点击"显示"按钮弹出窗孔展示历史记录."清空"按钮可以清空当前历史记录."保存"按钮会将当前历史记录保存到选中的文件中."加载"按钮用于读取之前保存的历史记录.
  历史记录文件是文本文件,每行一个数字,表示抽中的名字是名单中的第几行(空白行不进行编号,第一行编号是0).

  "界面"
  "界面"一栏用于控制显示效果."无滚动效果"勾选框用于控制是否有抽签过程中的滚动效果."滚动间隔(毫秒)"一栏中可以填写一个大于0的整数,表示滚动的时间间隔,单位是毫秒."显示更多"勾选框用于控制是否在主界面上显示常用设置.

快捷键:

  快捷键均只有在选中主窗口时才有效,在历史窗口,或者设置窗口上无效.
  P 点击用于抽签的"开始"(或"结束")按钮.
  B 显示或者隐藏常用设置.
  N 控制新抽结果是否会和已经抽到的结果重复.
  M 控制滚动效果开关.
